# OpenVidu Elastic installation

OpenVidu Elastic is part of the PRO edition of OpenVidu. You have the following deployment options:

- [**On-premises installation**](https://openvidu.io/3.5/docs/self-hosting/elastic/on-premises/install/): Set up OpenVidu Elastic on your own servers.
- [**AWS installation**](https://openvidu.io/3.5/docs/self-hosting/elastic/aws/install/): Deploy OpenVidu Elastic on Amazon Web Services.
- [**Azure installation**](https://openvidu.io/3.5/docs/self-hosting/elastic/azure/install/): Deploy OpenVidu Elastic on Microsoft Azure.
- [**Google Cloud Platform installation**](https://openvidu.io/3.5/docs/self-hosting/elastic/gcp/install/): Deploy OpenVidu Elastic on Google Cloud Platform.

Once your deployment is complete, refer to the following sections for configuration and management:

- [**On-premises: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/elastic/on-premises/admin/)
- [**AWS: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/elastic/aws/admin/)
- [**Azure: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/elastic/azure/admin/)
- [**Google Cloud Platform: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/elastic/gcp/admin/)

If you want to upgrade your OpenVidu Elastic installation, refer to this section:

- [**Upgrade OpenVidu Elastic On-premises**](https://openvidu.io/3.5/docs/self-hosting/elastic/on-premises/upgrade/)
- [**Upgrade OpenVidu Elastic AWS**](https://openvidu.io/3.5/docs/self-hosting/elastic/aws/upgrade/)
- [**Upgrade OpenVidu Elastic Azure**](https://openvidu.io/3.5/docs/self-hosting/elastic/azure/upgrade/)
- [**Upgrade OpenVidu Elastic Google Cloud Platform**](https://openvidu.io/3.5/docs/self-hosting/elastic/gcp/upgrade/)
