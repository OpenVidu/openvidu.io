# OpenVidu High Availability installation

OpenVidu High Availability is part of the PRO edition of OpenVidu. You have the following deployment options:

- [**On-premises installation (DNS Load Balancing)**](https://openvidu.io/3.5/docs/self-hosting/ha/on-premises/install-dlb/): Set up OpenVidu High Availability on your own servers with a DNS Load Balancing mechanism.
- [**On-premises installation (Network Load Balancer)**](https://openvidu.io/3.5/docs/self-hosting/ha/on-premises/install-nlb/): Set up OpenVidu High Availability on your own servers with a Network Load Balancer.
- [**AWS installation**](https://openvidu.io/3.5/docs/self-hosting/ha/aws/install/): Deploy OpenVidu High availability on Amazon Web Services.
- [**Azure installation**](https://openvidu.io/3.5/docs/self-hosting/ha/azure/install/): Deploy OpenVidu High Availability on Microsoft Azure.
- [**Google Cloud Platform installation**](https://openvidu.io/3.5/docs/self-hosting/ha/gcp/install/): Deploy OpenVidu Elastic on Google Cloud Platform.

Once your deployment is complete, refer to the following sections for configuration and management:

- [**On-premises: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/ha/on-premises/admin/)
- [**AWS: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/ha/aws/admin/)
- [**Azure: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/ha/azure/admin/)
- [**Google Cloud Platform: configuration and administration**](https://openvidu.io/3.5/docs/self-hosting/ha/gcp/admin/)

If you want to upgrade your OpenVidu High Availability installation, refer to this section:

- [**Upgrade OpenVidu High Availability On-premises**](https://openvidu.io/3.5/docs/self-hosting/ha/on-premises/upgrade/)
- [**Upgrade OpenVidu High Availability AWS**](https://openvidu.io/3.5/docs/self-hosting/ha/aws/upgrade/)
- [**Upgrade OpenVidu High Availability Azure**](https://openvidu.io/3.5/docs/self-hosting/ha/azure/upgrade/)
- [**Upgrade OpenVidu High Availability Google Cloud Platform**](https://openvidu.io/3.5/docs/self-hosting/ha/gcp/upgrade/)
