# OpenVidu Single Node PRO administration: Google Cloud Platform

In Google Cloud Platform, we recommend upgrading by redeploying [OpenVidu Single Node Google Cloud Platform](https://openvidu.io/3.4/docs/self-hosting/single-node-pro/azure/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node - On Premises](https://openvidu.io/3.4/docs/self-hosting/single-node-pro/on-premises/upgrade/index.md) section.
