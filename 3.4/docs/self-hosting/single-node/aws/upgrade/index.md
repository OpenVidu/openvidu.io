# Upgrade OpenVidu Single Node COMMUNITY - AWS

In AWS, we recommend upgrading by redeploying the [OpenVidu Single Node CloudFormation](https://openvidu.io/3.4/docs/self-hosting/single-node/aws/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node - On Premises](https://openvidu.io/3.4/docs/self-hosting/single-node/on-premises/upgrade/index.md) section.
