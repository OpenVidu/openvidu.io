# Upgrade OpenVidu Single Node PRO: AWS

AWS

In AWS, we recommend upgrading by redeploying the [OpenVidu Single Node CloudFormation](https://openvidu.io/3.6/docs/self-hosting/single-node-pro/aws/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node - On Premises](https://openvidu.io/3.6/docs/self-hosting/single-node-pro/on-premises/upgrade/index.md) section.
