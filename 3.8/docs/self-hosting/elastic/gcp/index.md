# OpenVidu Elastic Google Cloud Platform deployment

Google Cloud Platform

In this section you can install, administer and upgrade OpenVidu Elastic on Google Cloud Platform.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/elastic/gcp/install/index.md): set up a new Google Cloud Platform deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/elastic/gcp/admin/index.md): configure and manage your Google Cloud Platform deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/elastic/gcp/upgrade/index.md): update an existing Google Cloud Platform deployment to the latest version.
