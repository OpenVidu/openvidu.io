# OpenVidu Elastic deployment on Oracle Cloud Infrastructure

Oracle Cloud Infrastructure

In this section you can install, administer and upgrade OpenVidu Elastic on Oracle Cloud Infrastructure.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/elastic/oracle/install/index.md): set up a new Oracle Cloud Infrastructure deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/elastic/oracle/admin/index.md): configure and manage your Oracle Cloud Infrastructure deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/elastic/oracle/upgrade/index.md): update an existing Oracle Cloud Infrastructure deployment to the latest version.
