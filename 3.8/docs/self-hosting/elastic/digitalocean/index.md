# OpenVidu Elastic deployment on DigitalOcean

DigitalOcean

In this section you can install, administer and upgrade OpenVidu Elastic on DigitalOcean.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/elastic/digitalocean/install/index.md): set up a new DigitalOcean deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/elastic/digitalocean/admin/index.md): configure and manage your DigitalOcean deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/elastic/digitalocean/upgrade/index.md): update an existing DigitalOcean deployment to the latest version.
