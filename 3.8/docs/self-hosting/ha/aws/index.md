# OpenVidu High Availability deployment on AWS

AWS

In this section you can install, administer and upgrade OpenVidu High Availability on AWS.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/ha/aws/install/index.md): set up a new AWS deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/ha/aws/admin/index.md): configure and manage your AWS deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/ha/aws/upgrade/index.md): update an existing AWS deployment to the latest version.
