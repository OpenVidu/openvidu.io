# OpenVidu High Availability on-premises deployment

On-premises

In this section you can install, administer and upgrade OpenVidu High Availability on your own infrastructure.

- [**Install (DNS Load Balancing)**](https://openvidu.io/3.8/docs/self-hosting/ha/on-premises/install-dlb/index.md): deploy using DNS load balancing.
- [**Install (Network Load Balancer)**](https://openvidu.io/3.8/docs/self-hosting/ha/on-premises/install-nlb/index.md): deploy using a network load balancer.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/ha/on-premises/admin/index.md): configure and manage your on-premises deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/ha/on-premises/upgrade/index.md): update an existing on-premises deployment to the latest version.
