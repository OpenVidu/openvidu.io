# OpenVidu Single Node PRO deployment on DigitalOcean

DigitalOcean

In this section you can install, administer and upgrade OpenVidu Single Node PRO on DigitalOcean.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/digitalocean/install/index.md): set up a new DigitalOcean deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/digitalocean/admin/index.md): configure and manage your DigitalOcean deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/digitalocean/upgrade/index.md): update an existing DigitalOcean deployment to the latest version.
