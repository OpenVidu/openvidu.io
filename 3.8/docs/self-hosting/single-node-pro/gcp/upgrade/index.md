# Upgrade OpenVidu Single Node PRO: Google Cloud Platform

Google Cloud Platform

In Google Cloud Platform, we recommend upgrading by redeploying [OpenVidu Single Node PRO Google Cloud Platform](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/gcp/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node PRO without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node PRO - On Premises](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/on-premises/upgrade/index.md) section.
