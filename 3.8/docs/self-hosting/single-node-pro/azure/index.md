# OpenVidu Single Node PRO deployment on Azure

Azure

In this section you can install, administer and upgrade OpenVidu Single Node PRO on Azure.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/azure/install/index.md): set up a new Azure deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/azure/admin/index.md): configure and manage your Azure deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/azure/upgrade/index.md): update an existing Azure deployment to the latest version.
