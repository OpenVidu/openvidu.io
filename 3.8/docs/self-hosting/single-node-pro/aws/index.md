# OpenVidu Single Node PRO deployment on AWS

AWS

In this section you can install, administer and upgrade OpenVidu Single Node PRO on AWS.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/aws/install/index.md): set up a new AWS deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/aws/admin/index.md): configure and manage your AWS deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/aws/upgrade/index.md): update an existing AWS deployment to the latest version.
