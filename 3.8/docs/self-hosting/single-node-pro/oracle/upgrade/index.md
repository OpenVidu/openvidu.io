# Upgrade OpenVidu Single Node PRO: Oracle Cloud Infrastructure

Oracle Cloud Infrastructure

In Oracle Cloud Infrastructure, we recommend upgrading by redeploying [OpenVidu Single Node PRO Oracle Cloud Infrastructure](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/oracle/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node PRO without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node PRO - On Premises](https://openvidu.io/3.8/docs/self-hosting/single-node-pro/on-premises/upgrade/index.md) section.
