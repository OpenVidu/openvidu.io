# Upgrade OpenVidu Single Node COMMUNITY: DigitalOcean

DigitalOcean

In DigitalOcean, we recommend upgrading by redeploying [OpenVidu Single Node DigitalOcean](https://openvidu.io/3.8/docs/self-hosting/single-node/digitalocean/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node - On Premises](https://openvidu.io/3.8/docs/self-hosting/single-node/on-premises/upgrade/index.md) section.
