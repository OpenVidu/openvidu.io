# Upgrade OpenVidu Single Node COMMUNITY: Oracle Cloud Infrastructure

Oracle Cloud Infrastructure

In Oracle Cloud Infrastructure, we recommend upgrading by redeploying [OpenVidu Single Node Oracle Cloud Infrastructure](https://openvidu.io/3.8/docs/self-hosting/single-node/oracle/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node - On Premises](https://openvidu.io/3.8/docs/self-hosting/single-node/on-premises/upgrade/index.md) section.
