# Upgrade OpenVidu Single Node COMMUNITY: Google Cloud Platform

Google Cloud Platform

In Google Cloud Platform, we recommend upgrading by redeploying [OpenVidu Single Node Google Cloud Platform](https://openvidu.io/3.8/docs/self-hosting/single-node/gcp/install/index.md) with the latest version.

However, if you prefer to upgrade the OpenVidu Single Node without redeploying, you can follow the steps outlined in the [Upgrade OpenVidu Single Node - On Premises](https://openvidu.io/3.8/docs/self-hosting/single-node/on-premises/upgrade/index.md) section.
