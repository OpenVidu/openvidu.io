# OpenVidu Single Node COMMUNITY on-premises deployment

On-premises

In this section you can install, administer and upgrade OpenVidu Single Node COMMUNITY on your own infrastructure.

- [**Install**](https://openvidu.io/3.8/docs/self-hosting/single-node/on-premises/install/index.md): set up a new on-premises deployment.
- [**Admin**](https://openvidu.io/3.8/docs/self-hosting/single-node/on-premises/admin/index.md): configure and manage your on-premises deployment.
- [**Upgrade**](https://openvidu.io/3.8/docs/self-hosting/single-node/on-premises/upgrade/index.md): update an existing on-premises deployment to the latest version.
